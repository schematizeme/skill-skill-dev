Crie (ou **mescle**, preservando o que já existe) o `CLAUDE.md` na raiz do repo com o piso de autoria
de skills da casa, a partir de `.claude/skills/schematize-skill-dev/assets/CLAUDE.md`.

Regras da mesclagem: **não apague** regra existente; acrescente a seção de autoria de skills; se já
houver uma, **atualize-a** e diga o que mudou. O `CLAUDE.md` é sempre-on: vale para toda sessão neste
repo, sem ninguém precisar lembrar de carregar a skill.
